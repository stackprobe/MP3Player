MP3 Player 取扱説明書
=====================

■ 動作環境と起動

Windows 11 と .NET Framework 4.8 以降が必要です。
MP3Player.zip を展開し、MP3Player フォルダーの MP3Player.exe を
ダブルクリックしてください。実行ファイルと同梱の DLL などは
同じフォルダーに置いたまま使用してください。

■ 曲を追加する

エクスプローラーから MP3 ファイルやフォルダーをウィンドウに
ドラッグ＆ドロップします。複数のファイルやフォルダーをまとめて
追加できます。フォルダーを指定した場合は、直下にある MP3 が対象です。

一度に追加した曲はファイル名順で再生リストの末尾に入ります。
同じパスの曲は一度だけ登録されます。最初の追加で自動的に再生が
始まり、再生中に曲を追加しても現在の曲はそのまま再生されます。

コマンドプロンプトから起動するときは、ファイルやフォルダーを
引数に指定できます。次の例は MP3Player フォルダーで実行します。

  MP3Player.exe "C:\Music\a.mp3" "D:\My Music"

起動済みの場合は、指定した曲が開いているウィンドウに追加されます。

■ 再生を操作する

  一時停止   現在の曲を一時停止します。
  再生       一時停止した位置から再開します。
  曲の先頭   現在の曲を先頭から再生します。一時停止中も再生を開始します。
  前の曲     再生位置が 3 秒以内なら履歴の前の曲を再生します。
             履歴に前の曲がない場合や 3 秒を過ぎている場合は、
             現在の曲を先頭から再生します。
  次の曲     次の曲を再生します。履歴を戻った後は、再生モードを
             切り替えるまで履歴に沿って進みます。
  リセット   再生を停止し、登録した曲と再生履歴を消去します。
             再生モードは「順番ループ」に、曲番号は「0 / 0」に戻ります。

ファイル名の下に「曲番号 / 全曲数」を表示します。曲番号はシャッフル中も
登録順です。読み込みや再生に失敗した曲は飛ばされ、全曲数からも除かれます。

■ 再生モードを切り替える

モードボタンを押すたびに「順番ループ」「シャッフル」「1曲ループ」の
順に切り替わります。ボタンには現在のモードが表示されます。

  順番ループ   起動時のモードです。登録順に繰り返し再生します。
  シャッフル   曲をランダムな順で再生し、全曲を一巡するごとに
               シャッフルし直します。
  1曲ループ    現在の曲を繰り返します。「次の曲」を押すと、
               移動先の曲を繰り返します。

■ 終了する

ウィンドウを閉じると終了します。登録した曲や再生モードは保存されません。
